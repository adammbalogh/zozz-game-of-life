# Game of Life — zozz demó

Conway életjátéka egyetlen statikus oldalként: HTML, CSS és JavaScript, build és függőségek nélkül.
A funkciókat a zozz-coder agentjei készítik el, kártyáról kártyára.

- Élő oldal: https://adammbalogh.github.io/zozz-game-of-life/
- Helyben: nyisd meg az `index.html`-t a böngészőben.
- Tesztek: `npm test` (Node 24, `node --test`).
